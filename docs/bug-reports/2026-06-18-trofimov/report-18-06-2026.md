## Рабочий функционал

- **Cook with what? — выбор ингредиентов:** снятие галочек работает корректно, счётчик на кнопке "Generate from X items" обновляется в реальном времени. Генерация рецептов не работает из-за отсутствия бэкенда (Supabase) — это отдельная известная проблема.
- **Загрузка фото профиля из галереи:** работает корректно, фото устанавливается как аватарка.

## Наблюдения

---

### Экран: Build a Recipe → поля ввода ингредиента

**B01 — MEDIUM: Поле количества принимает текст**  
Поле (левая "таблетка", плейсхолдер "200") предназначено для числового значения, однако принимает произвольный текст. Валидация типа ввода отсутствует.

---

**B02 — MEDIUM: Поле количества не ограничено по длине**  
В числовое поле можно вводить бесконечно длинное число. Ограничение максимального значения или длины не установлено. При передаче на бэкенд может вызвать ошибку или краш.

---

**B03 — MEDIUM: Поле ингредиента принимает цифры**  
Поле (правая "таблетка", плейсхолдер "Chicken breast") предназначено для названия ингредиента, однако принимает цифры. Валидация типа ввода отсутствует.

---

**B04 — MEDIUM: Поле ингредиента не ограничено по длине**  
Текст в поле названия ингредиента можно вводить бесконечно. Максимальная длина не ограничена. Может привести к проблемам с отображением UI или крашу при обработке запроса.

---

**Общий вывод по B01–B04:**  
Оба поля не имеют валидации типа и длины ввода. При крайних значениях (очень длинный текст, огромное число, текст вместо числа) возможен краш приложения или некорректная работа генерации рецептов.

### Экран: Profile — длинное имя пользователя

**B05 — HIGH: Длинное имя ломает верстку экрана Profile**  
При вводе длинного имени (пример: "User18062026aaaaaaa...") имя не обрезается и не переносится корректно — оно занимает весь экран, перекрывая аватар, кнопки и остальной контент. UI полностью сломан.  
Дополнительный эффект: иконка карандаша (редактировать имя) стоит сразу после текста имени — при коротком имени она на месте, при длинном уезжает за пределы экрана и становится недоступной.  

**Ожидаемое поведение:**  
- Максимальная длина имени ограничена (например, 50 символов)  
- Длинное имя отображается с обрезанием и многоточием: `User18062026......`  
- Иконка карандаша всегда остаётся видимой рядом с именем  

Ограничение длины имени на уровне поля ввода отсутствует. Обрезание текста (`numberOfLines`, `ellipsizeMode`) в компоненте отображения имени не настроено.  
**Скриншот:** b05-long-name.png

### Экран: Profile — серый квадрат за аватаркой

**B07 — MEDIUM: Статус "NOT SIGNED IN" при наличии локального профиля**  
Пользователь прошёл онбординг, задал имя, добавил продукты в холодильник, установил аватарку — приложение хранит все данные. Однако на экране Profile отображается статус "NOT SIGNED IN". Для пользователя это противоречие: данные есть, а статус говорит что он не авторизован. Ожидаемое поведение — либо показывать "Local account" / "Not synced", либо не показывать статус вовсе пока нет облачного аккаунта.  
**Скриншот:** b05-not-signed-in.png

---

**B06 — MEDIUM: Аватарка отображается в сером квадрате**  
Фото профиля обрезается в круг корректно, но за ним виден серый квадратный контейнер. Углы квадрата выступают за пределы круглой маски. Аватарка должна отображаться без видимого фона.  
**Скриншот:** b05-not-signed-in.png

### Экран: Profile — смайлы в имени пользователя

**ЗАМЕТКА (не баг): Поле имени принимает эмодзи**  
Имя пользователя может содержать эмодзи — приложение их корректно отображает. Верстка при умеренной длине не ломается, карандаш на месте.  
Оценка: не баг, поведение нейтральное. Стоит уточнить у команды — намеренно ли это разрешено или просто не запрещено.  
**Скриншот:** note-emoji-name.png

### Платёжный сервис Adapty

**ЗАМЕТКА (известно, не баг): Adapty не подключён**  
При нажатии "Upgrade to FreshCheck Pro" появляется диалог "No Adapty key". Платёжный сервис Adapty намеренно не подключён — приложение находится на стадии разработки и ещё не вышло в релиз. Руководитель об этом осведомлён.

**ЗАМЕТКА (известно, не баг): Supabase не подключён**  
При попытке создать аккаунт появляется диалог "Sign up — Supabase is not configured in this build. Continue as guest to keep using the app locally." Бэкенд (Supabase) не настроен в dev-билде. Это также является причиной бага "Backend unavailable" на экране сканирования — всё из одного источника. Руководитель об этом осведомлён.
